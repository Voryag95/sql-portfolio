# Проект: Проектирование механизма отправки уведомлений о доставке

## Описание проекта
Разработка архитектуры и требований к системе отправки пуш-уведомлений об изменении статуса заказа для интернет-маркетплейса.

## Используемые инструменты
- SQL (структура данных)
- BPMN (моделирование процессов)
- API-дизайн (Swagger / OpenAPI)
- Google Docs / Excel (документирование)

## Результаты
1. **Функциональные и нефункциональные требования** — полный список требований к системе.
2. **Диаграмма бизнес-процесса (BPMN)** — визуализация процесса отправки уведомлений.
3. **Структура API** — описание взаимодействия с внешним сервисом доставки.

## Файлы проекта
- `Требования_к_приложению.xlsx` — полная спецификация
- `Диаграмма` — BPMN-схема процесса
- `Структура_API` — описание методов и форматов

## Выводы
- Система должна обрабатывать до 1000 уведомлений в минуту.
- Время обработки запроса — не более 2 секунд.
- Данные передаются по HTTPS, логи хранятся 30 дней.
- Реализована обработка ошибок и повторные попытки.
