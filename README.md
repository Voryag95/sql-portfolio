# sql-portfolio

Мои проекты по SQL и анализу данных для портфолио.

## Обо мне
Начинающий SQL-аналитик с опытом работы с данными более 3 лет. Владею SQL (продвинутый уровень), Python (базовый), Excel (сводные таблицы, Power Query). Ищу позицию аналитика данных / BI-разработчика.

## Проекты

### 1. Анализ продаж (Superstore)
[Подробнее](project_1_sales_analysis/README.md)
- Выручка по категориям, динамика по месяцам, топ-5 товаров.
- Инструменты: SQL (MariaDB), DBeaver.

### 2. Когортный анализ (Retention)
[Подробнее](project_2_retention_analysis/README.md)
- Оценка возвращаемости клиентов после первого заказа.
- Инструменты: SQL (MariaDB), оконные функции.

### 3. RFM-анализ
[Подробнее](project_3_rfm_analysis/README.md)
- Сегментация клиентов по давности, частоте и сумме покупок.
- Инструменты: SQL (MariaDB), CASE, подзапросы.

### 4. Проектирование системы уведомлений о доставке
[Подробнее](project_4_notification_design/README.md)
- Разработка архитектуры и требований к системе отправки пуш-уведомлений.
- Инструменты: SQL, BPMN, API-дизайн.

### 5. Python-проект: Анализ продаж
[Подробнее](python_projects/superstore_analysis/README.md)
- Визуализация данных: выручка по категориям, динамика по месяцам.
- Инструменты: Python (pandas, matplotlib, seaborn).
