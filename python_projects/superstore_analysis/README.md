# Проект: Анализ продаж Superstore (Python)

## Описание
Анализ данных интернет-магазина Superstore с помощью Python. Визуализация выручки по категориям и динамики по месяцам.

## Инструменты
- Python (pandas, matplotlib, seaborn, sqlalchemy)
- VS Code
